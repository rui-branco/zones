Layouts stay with your monitors, and the zone shortcut always moves the window.

- **Layouts follow the monitor, not Windows' number for it.** Windows renumbers displays now and then, after sleep, a reconnect or a driver update, and the ultrawide that was Display 1 becomes Display 2. Zones kept layouts by that number, so after a renumbering each screen came up with the other's layouts and sizes, which looked like they were lost. They are now kept by the monitor itself (its make, model and connector). Existing layouts move over by themselves on the first start, and a monitor moved to another connector keeps its layouts too.
- **Every press of the zone shortcut moves the window.** A window sitting almost exactly in a zone, as one left there by a size switch, used to be snapped into that same zone on the first press, so the press looked like it did nothing. A window within a few pixels of a zone now counts as in it, and the press moves it on.

Zones updates itself to this one. Otherwise download `zones.exe` (Windows) or `Zones-mac.zip` (macOS) below.
